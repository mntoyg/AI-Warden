# =============================================================================
#  AI Warden - Egress Allowlist
# -----------------------------------------------------------------------------
#  Squid `dstdomain` ACL entries. This is the COMPLETE list of destinations an
#  agent may reach. Anything absent from this file is denied with 403.
#
#  SYNTAX
#    example.com     exact host only
#    .example.com    example.com and every subdomain
#
#  Squid REJECTS a list that contains both a wildcard and one of its own
#  subdomains ("'registry.npmjs.org' is a subdomain of '.npmjs.org'") and
#  refuses to start. Pick one form per zone - and prefer the exact host.
#
#  RULES FOR EDITING
#    * Add the narrowest entry that works. Prefer `api.vendor.com` over
#      `.vendor.com`; prefer `.vendor.com` over adding a CDN wildcard.
#    * Never add a general-purpose host that can relay arbitrary traffic
#      (URL shorteners, pastebins, webhook catchers, tunnels, raw object
#      storage, Google Drive, Discord/Slack webhooks). Those turn an
#      allowlisted proxy into an exfiltration channel.
#    * Every addition widens the blast radius of a compromised agent.
#      Review this file the way you would review a firewall change.
#
#  Reload after editing:  make reload-proxy
# =============================================================================
